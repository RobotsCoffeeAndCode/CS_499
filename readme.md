### C++ Environment Setup

- Clang + UCRT64 (part of MSYS2) w/ C++ Version 20+
- CMake + Ninja for building
- clangd for linting / intellisense
- Google Test for automatically testing after build
- Static linking of libraries so the final compiled binary can be run anywhere

### Looking for a specific file?

- All implementation files are located in /src
- All header files are located in /include
